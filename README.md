# Exemplar Bank: legacy risk models, Quill to Python

> **ALL FICTIONAL.** Exemplar Bank, the Quill language, the RiskDB engine, every person, model,
> number and data file in this repo are invented for a sales demo. No real bank, no real people,
> no real proprietary code or data.

Ten liquidity, market and counterparty risk models written in **Quill**, a (fictional) in-house
risk DSL that only a few engineers ever knew. The goal: migrate each model to typed, tested
Python with **proven parity** against the legacy outputs, and surface anything in the legacy
code that looks wrong instead of copying it.

| Branch | State |
|---|---|
| demo branch (no suffix) | Before: legacy models, runtime, data, reference outputs, parity harness. `risk_models/` has only the shared libs. |
| same name + `-complete` | After: all 10 models in `risk_models/`, unit tests, parity report, one finding that needs a human decision. |

## Layout

| Path | What |
|---|---|
| `legacy/models/*.quill` | The 10 legacy models (source of truth) |
| `legacy/models/lib/*.quill` | Shared Quill libs: `rounding`, `daycount`, `stats` |
| `legacy/data/` | Fictional inputs: positions, funding, counterparties, rating tables, market data, scenarios |
| `legacy/data/cases/<model>.csv` | Test cases (15-40 per model, several as-of dates) |
| `legacy/reference_outputs/<model>.csv` | Outputs generated by running Quill. **Never edit by hand.** |
| `legacy/quill_runtime/` | Python interpreter that emulates the legacy RiskDB engine |
| `legacy/MODEL_INVENTORY.md` | Model list, authors, last change, owner status |
| `risk_models/` | Python target. `risk_models/common/` = ports of the Quill libs |
| `tests/runtime/` | Interpreter tests + "references regenerate exactly" |
| `tests/parity/` | Python port vs reference output, case by case |
| `tests/unit/` | Unit tests for the Python code |
| `docs/playbook-quill-to-python.md` | Devin playbook: migrate one model per session |
| `docs/DEMO.md` | Presenter script |

## Run it

Python 3.10+.

```bash
pip install -r requirements.txt

# legacy side
python -m legacy.quill_runtime lcr_outflows LCR-002   # one case
legacy/run_all.sh                                     # regenerate all reference outputs
legacy/run_all.sh --check                             # prove committed outputs reproduce exactly

# tests
pytest -v                    # everything
pytest tests/runtime         # interpreter
pytest tests/parity          # parity (skips models not migrated yet)
```

Parity rule: numeric fields must match within an absolute tolerance of `1e-9` (as `Decimal`),
text / dates / booleans must match exactly. See `tests/parity/test_parity.py`.
